# Demo 1 — Ride

## Description

This project presents a carousel ride with animated horses, selectable viewpoints, a completed-loop display, and switchable day/night lighting. The carousel rotates continuously while each horse bobs and tilts from its position around the ride.

## What it demonstrates

- Programmatic ride and horse animation driven by rotation and sine-wave motion.
- Camera switching between rider and environmental viewpoints.
- Runtime UI that counts completed rotations.
- A day/night presentation change using the scene skybox and directional light.
- A browser-oriented, public-facing VR experience.

## Controls

Use the on-screen controls to switch cameras and toggle the day/night lighting.
The camera can look with the mouse.

## Run locally

1. Open this folder as a Unity project using Unity `6000.3.22f1`.
2. Open `Assets/Scenes/SampleScene.unity`.
3. Enter Play mode, or make the final WebGL/WebXR build using the submitted build profile.
